**iKash** is a P2P fiat-to-crypto exchange built on the **Stellar network**. It bridges traditional finance and Stellar's liquidity to drive sustainable, real-world adoption.

🔗 **Live app:** [ikash.it.com](https://ikash.it.com)

**What it offers**
- 🤝 **P2P Marketplace:** non-custodial trading directly between users, with no middleman.
- 📊 **Transaction Intelligence:** real-time tracking and financial analytics.
- ⭐ **Stellar Native:** built around the network's speed and low transaction costs.

**What I built**
- **Frontend:** Next.js / React / Tailwind CSS app, including a `StatsDashboard` with Recharts that replicates the Figma design.
- **Frontend quality:** accessible focus management in modals, lazy loading with `next/dynamic`, and config-driven onboarding forms.
- **Backend:** NestJS API with TypeORM and Supabase PostgreSQL.
